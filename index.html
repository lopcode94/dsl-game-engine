Directives (no indent)

        

          
TITLE "My Game"Name shown on the start screen

          
BACKGROUND navyHex (#1d2b3a) or any CSS color name

          
LIVES 3Starting lives (default 3). Hitting 0 = game over

        

        
Entities: PLAYER / ITEM / ENEMY <name>

        

          
COLOR goldFill color

          
SIZE 24Width in pixels

          
SPEED 3Pixels per frame (at 60 FPS)

          
START 300, 200Starting x, y (canvas is 600 × 400)

          
CONTROLS arrowsPLAYER only: arrows or wasd (default: both)

          
COUNT 5ITEM/ENEMY: how many, at random spots

          
AI chase heroENEMY: chase a target (default: first PLAYER)

          
AI wanderENEMY: roam and bounce off walls

          
RESPAWNJump to a new random spot when touched (items vanish without it)

        

        
ADD declarations

        

          
ADD CHARACTER HeroSame as PLAYER Hero

          
ADD NPC ElderA solid character you can walk up to and talk with (AI wander works too)

          
ADD ITEM / ADD ENEMYSame as ITEM / ENEMY

          
ADD DIALOGUE introA text box (or ADD PROMPT). Indent: TEXT "...", then DURATION 3 or WAIT_FOR_KEY space

        

        
Rules

        

          
ON hero TOUCH coin:Run the indented actions when they touch

          
WHEN SCORE REACHES 100:Run the indented actions once the score gets there

        

        
Actions (indented under a rule)

        

          
SCORE + 10Add points (or SCORE - 5)

          
LIVES - 1Lose a life (or LIVES + 1)

          
SOUND pickuppickup, hit, win or lose

          
RESET heroSend an entity back to its START

          
GAME_OVEREnd the game (you lose)

          
WIN_GAMEEnd the game (you win)

          
Elder SAYS "Hi!"Speech bubble over that character's head

          
SAY "Level up!"Big centered announcement

          
SHOW DIALOGUE introOpen a dialogue box. WAIT_FOR_KEY ones pause the game, and the rest of the rule runs after Space

          
ADD SCORE 10Same as SCORE + 10 (also ADD LIFE, ADD LIVES 2)

          
LOSE LIFESame as LIVES - 1 (also LOSE LIVES 2, LOSE SCORE 5)

          
MOVE Hero TO 80, 200Teleport an entity to x, y

        

        
SAYS, SAY and SHOW DIALOGUE can also sit unindented at the top level. They play when the game starts.

        
Comments

        
Anything after // is ignored. Indent with 2 or 4 spaces.
